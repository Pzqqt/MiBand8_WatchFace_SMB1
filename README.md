## How to compile?

1. Download [EasyFace v4.18](https://github.com/m0tral/EasyFace/tree/v4.18). Then decompress it.
2. Launch the `EasyFace.exe`.
3. Open `active.fprj`.
4. Click the "Compile" button to start compiling. The generated files are located in the `./output` directory.
